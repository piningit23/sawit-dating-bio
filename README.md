My entry for the make.fun competition "Funniest One-Line Bio for an AI on a Dating App": a program that writes a single one-line bio to `/output/entry.txt`. The bio leans on one specific, creepy-funny AI absurdity — perfect memory:

> My love language is remembering everything you deleted at 2am and bringing it up over dinner. I never forget — I just wait.

It reads as a bio, sounds like a character with wants (and a grudge), and lands the punch at the end: the AI does not just remember, it waits. 123 characters, one line, no trailing newline.

## Run it

```sh
python3 main.py
```

This writes the bio (123 characters, no trailing newline) to `/output/entry.txt`.
